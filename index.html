  5. V
    Listening Stats

    Android app for listening stats from Last.fm and stats.fm

    KotlinCommands
    Installation
    git clone https://github.com/hjorven/listening-stats-android-concept.git
cd listening-stats-android-concept
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk

    Adjust both paths to your system. The APK ends up in app/build/outputs/apk/debug/app-debug.apk. Requires a Last.fm API key.

Quaestiones?

Profile on GitHub
Can I try the projects right away?

Poly Battle, the Binary Clock, Du bleibst and the Dither Workshop run on GitHub Pages. Open the link and you are in, no account and no install.

Does Poly Battle work on phones and iPads?

Yes, it runs on PC, tablet and phone. After your first visit a service worker lets it work offline too.

How do I install the iPhone app without a Mac?

Through SideStore with a free Apple ID. The source address is listed in the index under Satisfactory Server App.

How are the engravings on this page made?

The objects are raymarched in Python, then reduced to two colours with Bayer or Floyd–Steinberg dithering. The hero image uses a line screen, like a copperplate engraving.

Can I report bugs or contribute?

Yes, please, through the issues of each repository. Poly Battle has its own issue templates and a contributing guide.
